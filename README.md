## 📖 Overview

**Mysuru Dasara 2026** is a state-of-the-art, full-stack digital twin and cultural portal celebrating the world-famous "Nada Habba" (State Festival) of Karnataka. 

Designed and engineered with cutting-edge 3D WebGL graphics, spatial audio synthesis, IoT telemetry simulation, AI-powered multilingual conversational guidance, and royal heritage mini-games, this platform brings the majesty of Mysuru to audiences across the globe.

## ✨ Key Platform Features

### 🐘 1. Interactive 3D Lead Tusker Simulator & Gajapada Roster
- **Interactive 3D Ambari Tusker**: Control the decorated lead elephant carrying the 750kg Golden Howdah (*Chinnada Ambari*) with interactive speed, ear flutters, trunk salutes (*Gajaraja Namaskara*), and camera viewports.
- **Gajapada Roster**: Deep historical archives and biometric profiles for legendary lead tuskers including Arjuna, Abhimanyu, Drona, Balarama, and Bhima.

### 🎨 2. GI Crafts & Artisan Marketplace Showcase
- Dedicated platform spotlighting Mysuru's authentic Geographical Indication (GI) heritage:
  - **Mysore Silk** (KSIC 100% pure gold zari)
  - **Mysore Sandalwood Oil & Soap** (Government Sandalwood Oil Factory)
  - **Rosewood Inlay Marquetry** (Channapatna woodcrafts)
  - **Mysore Traditional Painting** (Gesso gold leaf relief)
  - **Ganjifa Circular Royal Playing Cards**
  - **Mysore Pak & Nanjangud Rasabale**
- Direct artisan bios, verified GI tag certification badges, and booking/inquiry workflows.

### 🃏 3. Mysore Ganjifa Royal Circular Playing Cards Mini-Game
- Faithful digital reproduction of the 16th-century Wodeyar royal card game (*Dashavatara Ganjifa*).
- Play against the AI with traditional circular cards, authentic suits (Matsya, Kurma, Varaha, Narasimha, etc.), scoring, and cultural trivia.

### 🎵 4. Spatial Royal Soundscape Mixer & Web Radio
- Persistent global audio console featuring 6 channel sliders:
  - Nadaswaram & Thavil
  - Royal Palace Durbar Chants
  - Temple Brass Bells
  - Procession Chenda Melam Drums
  - Mysore Evening Ambience & Cricket Chirps
  - Live Dasara Web Radio Stream
- Interactive soundboard with instant royal sound effects (Trumpet, Elephant Roar, Temple Bell, Shankha) and live canvas LED frequency visualizer.

### 🗺️ 5. Smart Map with Live IoT Parking & Shuttle Telemetry
- Interactive Leaflet-based festival corridor covering the entire 4.5 km Jamboo Savari procession route from Mysore Palace to Bannimantap Grounds.
- Real-time IoT parking slot trackers with capacity gauges for Palace South Gate, Exhibition Grounds, Town Hall, and Suburban Bus Stand.
- Live moving KSRTC electric feeder shuttle buses with simulated GPS coordinates and arrival timings.

### 📜 6. Public Certificate Verification Portal & Heritage Passport
- Cryptographically verifiable digital certificates for quiz champions and cultural ambassadors.
- Direct verification portal (`/verify`) with instant SHA-256 certificate lookup, recipient identity validation, and tamper-proof verification stamp.
- Gamified quiz system rewarding high-resolution vector PDF certificates.

### 🤖 7. Multilingual Royal AI Guide — "Kiran"
- Bilingual conversational concierge fluent in both **Kannada (ಕನ್ನಡ)** and **English**.
- Backed by Google Gemini AI and curated with deep local knowledge of royal rituals, schedules, transport, and history.

### 📸 8. Live Royal Photo Studio & Canvas Composer
- Real-time webcam integration and festival photo studio.
- Overlay authentic Dasara turbans (*Mysore Peta*), floral garlands, royal frames, and golden borders with instant high-resolution image export.

## 🛠️ Technology Architecture

### Frontend Architecture
- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript 5.7](https://www.typescriptlang.org/) (Strict type-checking)
- **3D Graphics & Simulation**: [Three.js](https://threejs.org/), [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber), [@react-three/drei](https://github.com/pmndrs/drei)
- **Styling & UI**: [Tailwind CSS v4](https://tailwindcss.com/), [Framer Motion](https://www.framer.com/motion/), [Lucide React](https://lucide.dev/)
- **Maps**: [Leaflet](https://leafletjs.com/) with OpenStreetMap tiles
- **Audio Synthesis**: Web Audio API (Spatial Gain Nodes, AudioContext, Canvas AnalyserNode)
- **PDF Generation**: [jsPDF](https://github.com/parallax/jsPDF) vector certificates
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **PWA**: Service Worker caching, offline support, install manifest

### Backend Architecture
- **Framework**: [Django 5.1 / 6.0](https://www.djangoproject.com/) + [Django REST Framework](https://www.django-rest-framework.org/)
- **AI Engine**: Backend-proxied Google Gemini API with rate limiting & sanitization
- **Database**: SQLite (Development) / PostgreSQL ready (Production)
- **CORS & Security**: Strict origins, safe environment variable fallbacks

## 🚀 Getting Started

### Prerequisites
- **Node.js** >= 20.x
- **Python** >= 3.11
- **npm** >= 9.x or **pnpm**

---

### 1. Frontend Setup

```bash
# Clone the repository
git clone https://github.com/Srujan73389/mysuru-dasara-2026.git
cd mysuru-dasara-2026/frontend

# Install dependencies
npm install

# Start the Vite development server
npm run dev
```

The frontend will run at: **`http://localhost:5173`**

To build for production:
```bash
npm run build
```

---

### 2. Backend Setup

```bash
cd ../backend

# Create and activate Python virtual environment
python -m venv venv

# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# Install backend dependencies
pip install -r requirements.txt

# Run migrations and seed festival data
python manage.py migrate
python manage.py seed_data

# Start the Django API server
python manage.py runserver 8000
```

The backend API will run at: **`http://localhost:8000`**  
Django Admin: **`http://localhost:8000/admin/`**
